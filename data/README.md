# Dataset directory

This directory intentionally contains no dataset yet.

Before adding images, document the source, license/permission, collection method, label definitions, and any restrictions. Do not commit private farmer data, identifiable people, exact farm coordinates, or third-party images without appropriate permission.

- `raw/`: original permitted samples; ignored by Git by default.
- `processed/`: reproducibly processed data; ignored by Git by default.

See [data collection guidelines](../docs/DATA_GUIDELINES.md).
