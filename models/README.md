# Model artifacts

No trained model is included yet. This is intentional: a model should only be added after the dataset and evaluation process are documented.

When a model is ready, record:
- model architecture and version;
- training dataset version and permitted source;
- input preprocessing and supported image types;
- class definitions and held-out test results;
- per-class precision, recall, F1, confusion matrix, and known limitations;
- model license and reproducibility instructions.

Large binary model files are ignored by Git. Use a suitable artifact or release strategy once there is a validated model.
